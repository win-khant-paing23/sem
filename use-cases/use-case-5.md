USE CASE: 5 Add a New Employee's Details

CHARACTERISTIC INFORMATION

Goal in Context
As an HR advisor I want to add a new employee's details so that I can ensure the new employee is paid.

Scope
Company.

Level
Primary task.

Preconditions
Employee has signed a contract and provided personal and payroll details.

Success End Condition
Employee details are stored accurately in the database.

Failed End Condition
Employee details are not stored in the database.

Primary Actor
HR Advisor.

Trigger
A new employee joins the company.

MAIN SUCCESS SCENARIO

HR advisor receives new employee details.

HR advisor enters details into the HR system.

System validates the provided details.

System saves the new employee record.

EXTENSIONS

Invalid or missing data provided:
System prompts HR advisor to correct or input missing data.

SUB-VARIATIONS
None.

SCHEDULE
DUE DATE: Release 1.0
